# DinoGo 前端設計規範

## 1. 技術與實作原則

- Vue 3，統一使用 `<script setup>`。
- 以 Bootstrap 5 class 為基礎，必要時補原生 CSS。
- 使用 `src/assets/styles/design-tokens.css` 的 CSS variables。
- 禁止使用 Tailwind、React、shadcn。
- 不可任意 hardcode 顏色、字級、間距、圓角與陰影。
- 不可自行增加設計稿沒有的功能。
- 不串接 API 時，先使用靜態資料。
- Header、Footer、Layout、MemberNav、SellerNav 必須共用，不可在各 view 重複實作。

## 2. 顏色規則

主要使用：

- 主色：`--color-primary`
- Hover：`--color-primary-hover`
- Active：`--color-primary-active`
- 淡色背景：`--color-primary-soft`
- 白色表面：`--color-surface`
- 頁面背景：`--color-bg`
- 淡背景：`--color-surface-soft`
- 邊框：`--color-border`
- 主要文字：`--color-text`
- 次要文字：`--color-text-muted`
- 輔助文字：`--color-text-subtle`
- 錯誤：`--color-danger`
- 成功：`--color-success`
- 警告：`--color-warning`

範例：

```css
.component {
  color: var(--color-text);
  background: var(--color-surface);
  border: 1px solid var(--color-border);
}

.component:hover {
  color: var(--color-primary);
  background: var(--color-primary-soft);
}
```

禁止直接寫：

```css
color: #526559;
background: #ffffff;
```

## 3. 字型與字級

- UI、導覽、按鈕、表單：`--font-body`
- 品牌、Hero、重要標題：`--font-heading`

常用字級：

| Token | 大小 | 用途 |
|---|---:|---|
| `--font-size-xs` | 12px | caption、meta |
| `--font-size-sm` | 14px | 次要文字、label |
| `--font-size-base` | 16px | 內文、導覽、輸入欄位 |
| `--font-size-md` | 18px | 小標題 |
| `--font-size-lg` | 22px | 區塊標題 |
| `--font-size-xl` | 28px | 頁面標題 |

## 4. 間距與圓角

間距使用：

| Token | 大小 |
|---|---:|
| `--space-1` | 4px |
| `--space-2` | 8px |
| `--space-3` | 12px |
| `--space-4` | 16px |
| `--space-5` | 24px |
| `--space-6` | 32px |
| `--space-7` | 48px |
| `--space-8` | 64px |

圓角使用：

- 小型元素：`--radius-sm`
- 按鈕、input：`--radius-md`
- 卡片：`--radius-lg`
- Avatar、badge：`--radius-pill`

Focus 使用：

```css
.component:focus-visible {
  outline: none;
  box-shadow: var(--shadow-focus);
}
```

## 5. Layout 邊界

### 一般商城

```text
UtilityBar
AppHeader
PrimaryNav
RouterView
AppFooter
```

### 會員中心

```text
UtilityBar
AppHeader
PrimaryNav
MemberNav
RouterView
AppFooter
```

### 商家中心

```text
SellerNav
RouterView
```

規則：

- `MemberNav` 只能放在 `MemberLayout`。
- `SellerNav` 只能放在 `SellerLayout`。
- 一般商城不可出現 MemberNav。
- Seller 頁不可混用 MemberNav。
- View 不可自行建立 Header 或 Footer。

## 6. Header 規格

### UtilityBar

- 高度約 48px。
- 背景：`--color-primary-900`。
- 左側：安心選物・透明交易・平台保障。
- 右側：最新消息、客服中心、幫助中心、繁體中文。
- 字級：14px。
- Container 最大寬度約 1440px。

### AppHeader

- 桌面高度約 130px。
- Logo icon：64×64px。
- 品牌文字：DINO-GO，約 28px／700。
- 副標：好物，慢慢挑，14px。
- SearchBar：56px 高。
- HeaderActions：icon 在上、文字在下。
- 通知 badge：2。
- 購物車 badge：3。

### SearchBar

- 高度：56px。
- 分類區：約 140px。
- 搜尋按鈕：約 64px。
- 外框：`--color-primary-500`。
- 分類背景：`--color-secondary-100`。
- Placeholder：搜尋商品、品牌或商家。

### PrimaryNav

- 桌面高度約 72px。
- 全部分類按鈕：160×52px。
- 導覽文字：16px。
- 商家中心靠右。
- 992px 以下使用收合導覽，避免水平溢出。

## 7. MemberNav 規格

整體：

- 桌面高度約 120px。
- 白色背景。
- 下方使用 `--color-border`。
- Container 最大寬度約 1440px。

會員資料：

- Avatar：56×56px。
- 背景：`--color-primary-100`。
- 文字：D，使用 `--color-primary-700`。
- 名稱：Dino 會員。
- 等級：一般會員。

導覽項目：

- 總覽
- 訂單
- 收藏
- 優惠券
- 訊息
- 帳戶設定

Active 狀態：

- 文字、icon、underline 統一使用 `--color-primary`。
- Underline 高度 4px。
- Underline 必須貼齊整個 MemberNav 底部，不可浮在 nav item 下方。

帳戶設定：

- 使用淡色背景。
- 顯示 `bi-chevron-down`。
- 目前只做樣式，不實作 dropdown。

## 8. Icon 規格

- 使用 Bootstrap Icons。
- 一般導覽 icon 約 18～20px。
- Header icon 約 20～24px。
- Icon 與文字間距使用 `--space-2`。
- Icon 顏色應繼承元件狀態。
- Icon 操作區至少 40px。
- Badge 不可取代原本 icon。

## 9. Active、Hover、Focus

所有可操作元件至少需要：

- Default
- Hover
- Active
- Focus-visible
- Disabled（適用時）

導覽 active 範例：

```css
.nav-link {
  color: var(--color-text-muted);
}

.nav-link:hover {
  color: var(--color-primary);
  background: var(--color-primary-soft);
}

.nav-link.router-link-active {
  color: var(--color-primary);
}
```

## 10. RWD 驗收尺寸

至少檢查：

- 375px
- 768px
- 1024px
- 1440px

要求：

- 不可產生整頁水平捲動。
- 手機導覽可收合或橫向捲動。
- 文字不得擠破版。
- Avatar 與會員名稱必須保持可讀。
- 桌面版比例需接近設計稿。

## 11. 元件責任

- Layout 元件只負責組合頁面骨架。
- `RouterView` 放在 Layout，不放入 MemberNav 或 SellerNav。
- 單頁內容留在 view。
- 只有跨頁重複使用時才抽成 component。
- 現階段不要提前建立 `MemberSummaryCards`、`OrderCard`、`CouponCard` 等細部元件。

## 12. Commit 前檢查

```bash
npm run build
git diff --check
git status --short
```

另外需確認：

- Browser console 無 error／warning。
- 沒有修改任務範圍外的檔案。
- 沒有使用 hardcode 顏色。
- 沒有引入 Tailwind、React、shadcn。
- 一般商城、會員中心、Seller layout 沒有互相混用導覽元件。
